# Marriage Readiness Diagnostic

Lead-generation web app for the Marriage Readiness Diagnostic by Fr. Michael C. Chime, JCD (catholicmarriagelife.com).

- `content/diagnostic-config.json` — canonical diagnostic content (questions, scoring, feedback copy)
- `docs/` — build and lead-generation plans
- `app/` — Vite + React + TypeScript web app (deployed to diagnostic.catholicmarriagelife.com)
